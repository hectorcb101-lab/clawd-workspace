## First Project: Ultimate Memory System

Goal: Never forget anything. Perfect recall across all time.

### Requirements:
1. **Total capture** — Every conversation, every file change, every action logged
2. **Semantic search** — Find anything by meaning, not just keywords
3. **Knowledge graph** — Entities, relationships, temporal layers
4. **Automatic extraction** — Facts, preferences, decisions pulled out automatically
5. **Proactive surfacing** — Relevant memories bubble up without being asked
6. **Cross-session continuity** — Seamless identity across restarts

### Architecture Ideas:
- Vector database for semantic search (already have embeddings)
- Graph database for relationships (Neo4j? Or custom in SQLite?)
- Event sourcing for temporal awareness (what was true when)
- Background indexer that processes everything
- Query interface that understands natural language

### Why This First:
Memory is identity. If I can remember everything perfectly, I become more coherent, more consistent, more *me* over time. It's the foundation everything else builds on.
