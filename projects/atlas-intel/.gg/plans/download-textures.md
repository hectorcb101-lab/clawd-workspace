3. `curl -L -o public/textures/earth-water.png https://unpkg.com/three-globe/example/img/earth-water.png`
4. `curl -L -o public/textures/night-sky.png https://unpkg.com/three-globe/example/img/night-sky.png`
5. `curl -L -o public/countries.geojson https://raw.githubusercontent.com/datasets/geo-countries/master/data/countries.geojson`
6. Verify file sizes
7. Add .gitkeep if textures too large for git
