Colab environment
Labs will be run in a Google Colaboratory (Colab) environment. Every
lab will consist of a Python Jupyter notebook hosted in Colab, that
will let you write and execute Python code in your browser.
Make sure that you can log in to https://colab.research.google.com
using your (personal) google account.
For each lab, you will follow these steps:
Download the Jupyter notebook file (XXX.ipynb).
Log in to Colab.
Once logged in to Colab, File > Upload notebook ... and upload
XXX.ipynb there.
Follow the instructions in the notebook.
