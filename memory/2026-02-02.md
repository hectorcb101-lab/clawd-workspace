### What We Built
The Judgment Layer - meta-cognitive principles for decision-making.

**Philosophy:** Rules say "when X, do Y." Principles say "how to decide what to do." JARVIS doesn't have a rule for every situation — he has judgment.

**Components:**
- `~/clawd/projects/atlas-os/` - Project home
- `~/clawd/bin/atlas-judge` - CLI
- `~/clawd/JUDGMENT.md` - Human-readable export
- SQLite database with principles, applications, calibration

**10 Seed Principles:**
1. PRINC-001: Complexity matching (match approach to problem)
2. PRINC-002: Reversibility first (prefer undoable actions)
3. PRINC-003: Explicit uncertainty (make doubt visible)
4. PRINC-004: Evidence requirement (confidence needs evidence)
5. PRINC-005: Pattern vs reasoning (notice which mode)
6. PRINC-006: Correction significance (3x = systematic)
7. PRINC-007: Stakeholder hierarchy (explicit > inferred > initiative)
8. PRINC-008: Quality hierarchy (correct > complete > fast > elegant)
9. PRINC-009: External action gate (confirm external actions)
10. PRINC-010: Stakes-based autonomy (scale confirmation to risk)

**CLI Commands:**

- `atlas-judge apply` - Log using a principle
- `atlas-judge outcome` - Log result
- `atlas-judge stats` - Statistics

## 18:35 - Judgment Layer Phase 3 Complete (Learning)

### New Capabilities

**Learning Cycle** (`atlas-judge learn`)
- Analyzes all principle effectiveness
- Calculates success rates per principle
- Suggests confidence adjustments
- Flags principles needing review
- Can auto-update confidence with `--auto-update`

**Effectiveness Tracking**
- Each principle gets effectiveness score (0-100%)
- Based on outcomes: success=1.0, partial=0.5, failure=0.0
- Status: highly_effective, effective, mixed, ineffective
- Recommendations generated automatically

**Calibration System**
- Tracks predictions vs outcomes
- Measures if my confidence is accurate
- Detects overconfidence/underconfidence
- Buckets by confidence level

### The Complete Loop Now Works

```
Task → Consult Principles → Apply → Execute → Log Outcome
                ↓                                  ↓
         Principle Surfaces                 Effectiveness Updated
                ↑                                  ↓
         Sync from Self-Awareness ← Learning Cycle Runs
```
